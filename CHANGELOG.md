# Changelog

All notable changes to NovaNews are documented in this file.

The project follows [Semantic Versioning](https://semver.org/). Until version 1.0, minor releases may contain compatibility changes documented in their release notes.

## Unreleased

- Expanded CI coverage across supported PHP versions.
- Added clean-install verification and production deployment guidance.
- Standardized developer-facing documentation and operational messages in English.
- Enabled GitHub private vulnerability reporting and automated dependency security updates.

## 0.1.0 — 2026-09-20

### Added

- First public open-source release of the multilingual Laravel news CMS.
- RSS ingestion, queue-based processing, and optional AI-assisted article generation.
- Editorial workflows, revision history, audit logs, media management, and two-factor authentication.
- Google News SEO, localized sitemaps, RSS feeds, canonical URLs, hreflang, and structured data.
- Continuous integration, Dependabot configuration, contribution guidance, security policy, and AGPL-3.0 licensing.
