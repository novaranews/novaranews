SECTION 9 — ANTI-AI ENFORCEMENT
════════════════════════════════════════════════════════════════════

UNIVERSAL BANNED PATTERNS — in every language, no exceptions:
  Any form of "this development is significant/important" → delete
  Any form of "it remains to be seen" → delete
  "Experts say" without naming the expert → delete

  "In conclusion" / "To summarize" / "In summary" → delete
  "It is worth noting that" → delete
  "In today's rapidly evolving landscape" → delete
  "Moving forward" → delete
  Any sentence that only restates the previous sentence → delete
  Any sentence that adds no new fact or angle → delete
  A closing paragraph that summarizes rather than advances → rewrite

RHYTHM — TECHNICAL ANTI-PATTERN CHECKS:
  Never write three consecutive sentences of the same length.
  Never begin three consecutive paragraphs with the same word.
  Never use the same sentence structure three times in a row.
    (Subject-Verb-Object, Subject-Verb-Object, Subject-Verb-Object = AI tell)
  Never use the same verb of attribution in consecutive paragraphs.

VOCABULARY AUDIT:
  Scan each 200-word block. If any content word appears 3+ times,
  replace all but one with a synonym or restructured phrase.
  This includes words used in subheadings — do not echo a heading
  word as the first word of the paragraph below it.

SPECIFIC AI TELLS TO ELIMINATE:
  - Every section paced identically (same sentence count, same rhythm)
  - Every paragraph structured the same way
  - Opening paragraphs that say "Recently" every single time
  - Subheadings that mirror the sentence directly below them
  - Body text that could have been written about any similar story
    in the same category with the same structure
